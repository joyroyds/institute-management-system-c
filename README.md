# 🎓 Education Institute Management System

A C-based project designed to manage student records, fee payments, course allocations, and examination results using **Structures and Binary File Handling**.

## 🚀 Features
- Admin Login Authentication
- Student Registration, Search, Update & Delete
- View All Student Records
- Fee Payment Management
- Course Allocation (DS, AI, ML, Web)
- Result Management
- Course-wise Reports
- Change Password

## 🛠️ Technologies Used
- C Programming
- Structures
- Functions
- Pointers
- Binary File Handling

## 📂 Data Files
| File | Purpose |
|---|---|
| students.dat | Student Records |
| allocations.dat | Course Details |
| results.dat | Student Results |
| users.dat | Login Credentials |

## ⚙️ How to Run

**1. Compile**
```bash
gcc -Wall -o institute institute.c
```

**2. Run**
```bash
./institute
```

Windows:
```bash
institute.exe
```
